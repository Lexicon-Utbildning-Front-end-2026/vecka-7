## 🎯 Mål för veckan

* Efter denna vecka ska du:
* Förstå och kunna definiera egna typer för objekt med **interfaces** (och/eller `type`).
* Förstå **Document Object Model (DOM)** och kunna interagera med HTML-element: hämta, modifiera, skapa och lägga till element dynamiskt.
* Kunna hantera **händelser (events)** på DOM-element (t.ex. `click`) för att skapa interaktiva webbapplikationer.

## 📅 Tisdag: TypeScript Typer

Vi kommer gå lite mer på djupet för att förstå Typescript's olika Typer, som:

- type
- union types
- litaral types
- interfaces

Vi kommer även kort påminna oss om optional properties, och hur vi använder typer på funktioner.

Till sist går vi även igenom hur vi jobbar med metoder i våra objekt.
